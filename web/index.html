    How the AI is used, and how it isn't

    1. You ask a question in plain English.
    2. The AI fills in a small form from table and column names. It never sees a row of your data.
    3. Plain code checks the form against a list of what the database may show. Hidden columns are not on it.
    4. Code writes the SQL from the form and runs it read-only. The AI never writes SQL.
    5. You get the rows and the SQL. When the question can't be answered safely, it says so instead of guessing.
